A lightweight, pluggable memory layer that extracts, stores, and retrieves context for any OpenAI-compatible LLM

Why Recall?

Pluggable Architecture

Works seamlessly with any OpenAI-compatible API including OpenAI, Groq, Anthropic, and more. Just plug and play!

Smart Memory Extraction

Automatically identifies and extracts memory-worthy facts from conversations with configurable strategies.

Rich Metadata

Store memories with TTL, tags, importance scores, and source tracking for intelligent retrieval.

Context Injection

Automatically injects relevant memories into prompts, giving your LLM the context it needs.

Multi-User Support

Built-in user isolation ensures each user's memories remain private and organized.

Import/Export

Easy backup and restore capabilities with JSON export/import for memory persistence.

Add Memory Layer

Wrap your LLM with Recall's memory capabilities

Python 
# Install via pip
pip install recall-sdk
from recall import withrecall
from recall.memory import MemoryStore
from recall.llm.llm_client import create_openai_client

# Initialize your LLM client
llm = create_openai_client(
    api_key="your-api-key",
    base_url="https://api.groq.com/openai/v1",
    model="mixtral-8x7b-32768"
)

# Create a memory store
store = MemoryStore()

# Wrap with recall
with_recall = withrecall(llm=llm, store=store)

# Start chatting with memory!
response = with_recall.chat("My dog's name is Ollie.")
print(response)

# Later conversations will remember
response = with_recall.chat("What's my dog's name?")
# Response: "Your dog's name is Ollie!"
# Advanced configuration
with_recall = withrecall(
    llm=llm,
    store=store,
    user_id="user-123",  # Separate memories by user
    strategy="batch",    # Batch memory extraction
    metadata={"session": "chat-001"}
)

# Manual memory management
with_recall.remember(
    "I live in Berlin.",
    tags=["location", "personal"],
    importance=0.9
)

# Export memories
store.export_memories("user-123", path="backup.json")

API Reference

Method

withrecall()

Creates a memory-enhanced LLM wrapper that automatically manages context.

llm Callable - Your LLM client
store MemoryStore - Memory storage instance
user_id str (optional) - User identifier
strategy str - "always" | "batch" | "heuristic"
Method

chat()

Processes a message with automatic memory extraction and context injection.

message str - User's input message
Method

remember()

Manually stores a memory entry with custom metadata.

content str - Memory content to store
tags List[str] - Categorization tags
importance float (0-1) - Relevance score
Class

MemoryEntry

Core data structure for storing memories with rich metadata.

id UUID - Unique identifier
user_id str - User association
content str - Memory content
created_at datetime - Creation timestamp
tags List[str] - Categorization
importance float - Relevance score
ttl_days int - Time to live
